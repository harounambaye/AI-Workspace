# AI-Workspace

Plateforme web permettant aux collaborateurs d'une entreprise d'accéder et d'utiliser différents services d'Intelligence Artificielle via une interface unifiée.

## Description

AI-Workspace est l'interface utilisateur (Front-End) d'une plateforme destinée à centraliser l'accès à plusieurs services d'IA au sein d'une entreprise. Ce projet constitue la première étape du développement : la mise en place d'une interface fonctionnelle et ergonomique, prête à communiquer avec les APIs des modèles IA dans une phase ultérieure.

## Objectif

Avant l'intégration des modèles d'Intelligence Artificielle, l'équipe Front-End développe une interface utilisateur permettant :
- Une navigation simple et intuitive entre les différents services IA
- Une base solide pour la future communication avec les APIs
- Une expérience utilisateur cohérente pour l'ensemble des collaborateurs

## Technologies utilisées

- **HTML5** — structure des pages
- **CSS3** — mise en forme et responsive design
- **JavaScript** — interactivité (sans framework)

## Installation et utilisation

1. Cloner le dépôt :
   ```bash
   git clone https://github.com/harounambaye/AI-Workspace.git
   ```
2. Ouvrir le fichier `index.html` dans un navigateur web.

Aucune dépendance ni installation supplémentaire n'est requise, le projet étant développé en HTML, CSS et JavaScript natifs.
